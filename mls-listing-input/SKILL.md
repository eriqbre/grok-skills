# MLS listing input

## How the form opens

Stellar Matrix → Wolf Transaction Desk. Use the URL he provides.

## Fill from

- Previous MLS form
- Listing agreement
- Tax / Realist
- HOA
- Flood
- Seller names
- List price
- Expiration
- Buyer-broker comp

Do not invent.

Always fill Room Type rows from Rays floor plan (dimensions) + Rays photos (closet / fans / flooring).

## After

1. Seller + broker sign.
2. Email `listings@coastalpgi.com` (cc Bridget and Eriq) the signed package.
3. Track until MLS#.
4. Public remarks are often Bridget.
